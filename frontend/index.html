📖 Setup Guide

1. Copy .env.example to .env

2. Add your Gemini API key from Google AI Studio

3. For TTS, create a service account in Google Cloud Console and set the JSON path

4. Restart the application to load new credentials

GOOGLE_PROFILE_1_API_KEY=your-gemini-api-key-here
GOOGLE_PROFILE_1_TTS_CREDENTIALS=path/to/service-account.json

DEFAULT_IMAGE_MODEL=gemini-2.5-flash-image
DEFAULT_VIDEO_MODEL=veo-3.1-fast-generate-preview
